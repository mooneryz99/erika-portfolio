# Portfólio — Erika Ribeiro Santos

Site pessoal responsivo feito com HTML, CSS e JavaScript. O arquivo `cv-data.json` guarda os dados estruturados do currículo seguindo o modelo fornecido na atividade.

## Arquivos
- `index.html`: conteúdo e estrutura do site.
- `style.css`: identidade visual e responsividade.
- `script.js`: comportamento simples da página.
- `cv-data.json`: currículo estruturado no formato JSON solicitado.

## Visualizar
Abra `index.html` no navegador.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `erika-portfolio`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)` e salve.
6. Aguarde a publicação.

Endereço esperado: `https://mooneryz99.github.io/erika-portfolio/` (só ficará ativo após publicar).

## Observações
Campos sem informação confirmada foram mantidos vazios no JSON ou indicados como não informados no site. Datas do estágio e do curso, nome da escola onde ocorreu o estágio, telefone, LinkedIn, certificados, cursos adicionais e URLs individuais de projetos podem ser adicionados quando disponíveis.
